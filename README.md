# eruda-bookmarklet

Bookmarklet per aprire la console Eruda dentro una pagina su Chrome Android (totem, debug remoto).

1. Apri bookmarklet.txt (raw) sul tablet, copia tutto il testo.
2. Crea un preferito in Chrome, nome `eruda`, incolla il testo nel campo URL.
3. Sulla pagina da ispezionare scrivi `eruda` nella barra e tocca il suggerimento del preferito.
